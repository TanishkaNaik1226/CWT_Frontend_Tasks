## 🚀 Frontend Development Projects

As part of my frontend development internship, I completed a series of projects designed to build practical skills in HTML5, CSS3, JavaScript, responsive design, and browser-based data storage.

### 📌 Week 1 – Responsive Personal Portfolio Website

A modern and responsive personal portfolio website built using HTML5 and CSS3.

**Features:**
- Responsive layout for desktop, tablet, and mobile
- Flexbox and CSS Grid
- About, skills, education, projects, and contact sections
- Modern and professional UI
- Responsive navigation

**Technologies:** `HTML5` `CSS3` `Flexbox` `CSS Grid`
